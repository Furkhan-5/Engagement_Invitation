# Engagement Invitation — Dr. Farhan Lateefi & Dr. Zareen Basri

A single-page animated engagement invitation: a maroon envelope opens on tap to reveal the invitation, followed by the message, event details, countdown, venue, directions and RSVP.

## Edit the details
Open `index.html` and edit the `invitationData` block in the `<script>` near the bottom: names, date/time, venue, Google Maps link, WhatsApp number (country code, no +), and optional music file.

## Run locally
Open `index.html` in a browser. No build step or dependencies.

## Deploy on Vercel
1. Push this repo to GitHub.
2. In Vercel: Add New -> Project -> import the repo.
3. Framework Preset: Other. Leave Build Command and Output Directory empty. Deploy.

Every commit to the main branch redeploys automatically.
